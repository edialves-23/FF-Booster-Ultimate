
# 🔥 FF BOOSTER ULTIMATE

Otimizador e monitor de desempenho para Windows,
desenvolvido em C# WPF e .NET 8.

## Hardware de referência

- Intel Core i5-10400F
- NVIDIA GTX 1060
- 16 GB RAM
- BlueStacks 5 Pie 64-bit
- Free Fire normal
- Monitor 75 Hz

## Recursos

- Monitoramento de CPU.
- Monitoramento de memória RAM.
- Leitura de GPU NVIDIA via nvidia-smi.
- Detecção automática do BlueStacks.
- Ajuste reversível de prioridade.
- Plano de energia de alto desempenho.
- Restauração das configurações anteriores.
- Interface gamer preta e vermelha.

## Requisitos

- Windows 10 ou 11.
- Visual Studio 2022.
- .NET 8 SDK.
- Carga de trabalho Desenvolvimento para desktop com .NET.

## Como compilar

Abra FFBoosterUltimate.csproj no Visual Studio.

Selecione Release e clique em:

Build > Build Solution.

## Observações

O programa não garante aumento de FPS.
Ele aplica ajustes do Windows e monitora recursos.
O FPS real depende do jogo, emulador e hardware.
